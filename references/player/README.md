# Modeling references

The supplied front/rear blue-plaid protagonist screenshots define the outfit, hair silhouette and backpack. Published promotional artwork (https://www.4gamer.net/games/945/G094534/20250912067/screenshot.html?num=022) informs approximate large-head/short-leg proportions and continuous slender arms with open hands. The head including hat is approximately 59% of this reconstruction’s total height. This is an authored fan reconstruction, not an official mesh.

The v1 Blender and GLB files are retained only as historical backups outside the shipped public folder.
