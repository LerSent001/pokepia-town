# Contributing

Thank you for improving Pokopia Town.

1. Fork the repository and create a focused branch.
2. Run `npm install`, `npm test`, and `npm run build` before submitting a pull request.
3. Keep interface copy in English and preserve keyboard and screen-reader labels.
4. Keep the 30 FPS target in mind. Document meaningful changes to draw calls, triangle count, or frame timing.
5. Add every third-party asset to `THIRD_PARTY_NOTICES.md` with its author, source URL, exact license, and modified files.
6. Do not submit extracted game files, unlicensed artwork, secrets, generated build folders, or personal evidence logs.

By submitting a contribution, you certify that you have the right to license your contribution under the project's MIT License. Third-party material remains under its original license.
